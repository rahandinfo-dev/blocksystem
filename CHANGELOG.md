# Changelog

## 1.0.0 — 2026-09-30

- Construction quantity, cost, scenario and BOQ calculations using canonical metric project data.
- Persistent issued quotations and reports with multilingual PDF output, QR verification, revocation and SHA-256 document fingerprints.
- Security controls for server configuration, authentication, RBAC, project collaboration, audit records, backups and recovery.
- Progressive web application support with privacy-safe caching and operational health reporting.
- Responsive 2D floor-plan and 3D engineering visualisation workspaces, including measurement, selection, clipping, exploded views and screenshots.
- Kurdish, Arabic and English (United Kingdom) interfaces with RTL/LTR-safe engineering views.

BlockSystem is an engineering visualisation and estimating application. It does not provide structural certification, BIM compliance or a digital-signature service.
